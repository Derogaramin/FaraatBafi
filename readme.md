# سامانه جامع مدیریت تعاونی فرت‌بافی 🧵

**بازنویسی یکپارچهٔ سامانهٔ «تعاونی تولیدی صنایع دستی نقشینه بافت تربت جام» (برند فرت) با PHP 8.2 و MySQL/MariaDB**

یک سامانهٔ کامل مدیریت زنجیرهٔ ارزش — از سفارش مشتری تا تخصیص به بافنده، کنترل کیفیت، فروش، امور مالی و حاکمیت تعاونی — با معماری **ماژولار HMVC + رویدادمحور (ED) + MVC**، رابط کاربری تمام‌فارسی، **تقویم شمسی**، **تم روز و شب**، فونت **وزیرمتن** و نظام کدگذاری یکپارچهٔ **FUCS v3**.

## ✨ ویژگی‌ها

| حوزه | امکانات |
|---|---|
| 🛍️ بازارگاه | کاتالوگ با فیلتر نوع/رنگ/طرح، صفحهٔ محصول با مشخصات فنی، سبد خرید، پرداخت مهمان، کد تخفیف، پیگیری سفارش با کد ORD |
| 🧶 مدیریت تولید | سفارش بافت (WO)، تخصیص به بافنده، توزیع مواد اولیه، ماشین حالت وضعیت‌ها، بازرسی کیفیت (QC)، صدور خودکار کد اصالت |
| 🔐 اصالت محصول | کد یکتای `FB-سال-سری-بافنده` + **QR حاوی آدرس صفحهٔ اصالت** (نام بافنده، مشخصات بافت، تاریخ) |
| 👩‍🌾 پنل بافنده | طراحی موبایل‌محور، دکمه‌های بزرگ انگشتی (دریافت مواد ← شروع بافت ← تحویل)، شمارندهٔ معکوس موعد، فیش‌های دستمزد |
| 🏪 پنل نمایندگی | داشبورد فروش منطقه‌ای، **فروش حضوری (POS)** با اسکن SKU، کالای امانی، پورسانت خودکار (COM) |
| 👤 پنل مشتری | میز کار، سفارش‌ها، تیکت پشتیبانی، پروفایل |
| 📊 پنل مدیر | داشبورد KPI، نمودار فروش ماهانهٔ شمسی، مدیریت کاتالوگ (نوع/مدل فنی/رنگ/طرح/SKU)، سفارش‌ها، بافندگان، نمایندگی‌ها، انبار، مالی، BI |
| 💰 امور مالی | فیش دستمزد (PAY)، پورسانت (COM)، اسناد حسابداری (ACC)، گزارش‌های ماهانهٔ شمسی |
| 🏛️ حاکمیت | جلسات (MT)، مصوبات (RES)، رأی‌گیری (VOT)، مکاتبات داخلی (IR) |
| 📝 محتوا و پشتیبانی | وبلاگ، تیکت‌ها (TKT)، اعلان‌های زنده |
| 🎨 رابط کاربری | سبک «مینیمالیسم گرم و بافت‌دار»، پالت زرشکی/فیروزه‌ای/کرم، **تم روز/شب**، فونت وزیرمتن (لوکال)، اعداد و تاریخ فارسی، Toast و مودال تأیید |
| 🔒 امنیت | RBAC نقش‌محور، CSRF، bcrypt، **احراز دو مرحله‌ای (TOTP)** برای عملیات حساس، **محدودسازی نرخ ورود**، انقضای نشست، تغییر گذرواژهٔ اجباری، CSP/HSTS، **ممیزی قبل/بعد فیلدهای حساس** |
| 🧰 عملیات | صف رویدادها با کارگر و retry، کش مسیرها، ETag/304، خروجی CSV، اسناد چاپی A4، جست‌وجوی جهانی با پرش کد FUCS، Docker + CI |

## 🚀 شروع سریع

### پیش‌نیازها
- PHP ≥ 8.2 (با افزونه‌های `pdo_mysql`, `mbstring`, `gd`)
- MySQL 5.7+ یا MariaDB 10.4+
- Composer

### نصب

```bash
# ۱) نصب وابستگی‌ها
composer install

# ۲) تنظیم محیط
cp .env.example .env
# مقادیر DB_* و APP_URL را در .env ویرایش کنید

# ۳) ساخت پایگاه داده
mysql -u root -p -e "CREATE DATABASE faraatbafi CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -p -e "CREATE USER 'faraat'@'localhost' IDENTIFIED BY 'گذرواژهٔ شما'; GRANT ALL ON faraatbafi.* TO 'faraat'@'localhost';"

# ۴) مهاجرت + دادهٔ نمونه
php bin/faraat fresh

# ۵) اجرای سرور توسعه
php bin/faraat serve        # → http://localhost:8080
```

### حساب‌های نمونه (گذرواژهٔ همه: `faraat1403`)

| نقش | شناسهٔ ورود | پنل |
|---|---|---|
| عضو اصلی (هیئت‌مدیره) | `M001` | `/admin` — دسترسی کامل شامل مالی و حاکمیت |
| مدیر اجرایی | `S001` | `/admin` — بدون مالی/حاکمیت |
| بافنده | `W001` … `W008` | `/weaver` — پنل موبایل‌محور |
| نمایندگی | `A01` … `A05` | `/agency` — داشبورد و POS |
| مشتری | `C000001` … `C000008` | `/my` — سفارش‌ها و تیکت‌ها |

## 🆕 در نسخهٔ ۲٫۱ (چرخهٔ اصلاح بر اساس نقد)

- فاز ۰ نقشهٔ راه **تکمیل شد**: 2FA/TOTP، rate-limit ورود، انقضای نشست، CSP/HSTS،
  حذف آپلود SVG، ممیزی فیلدمحور، ماشین حالت `OrderFlow` با enum، صف رویدادها + کارگر،
  کش مسیرها، ETag/304، اعمال سقف اعتبار نمایندگی در POS، Docker + GitHub Actions CI
- ~۷۰٪ فاز ۱٫۵ زودتر از برنامه انجام شد: date-picker شمسی، فاکتور/فیش چاپی A4،
  خروجی CSV، جست‌وجوی جهانی `/search`، polling اعلان‌ها، WebP، skip-link/aria-live
- رفع باگ عملیاتی: هم‌ترازی منطقهٔ زمانی DB با PHP (ADR-007)
- تست‌ها از ۱۰۸ → **۱۳۸** و خزش صفحات از ۹۱ → **۹۹** رسید

## 🧱 معماری در یک نگاه

```
faraatbafi/
├── app/
│   ├── Modules/            ← ۱۳ ماژول خودبسنده (HMVC)
│   │   └── [Name]/
│   │       ├── module.json     شناسنامهٔ ماژول
│   │       ├── routes.php      مسیرها
│   │       ├── events.php      شنونده‌های رویداد (ED)
│   │       ├── menu.php        آیتم‌های منوی پنل‌ها
│   │       ├── Controllers/    کنترلرها (MVC)
│   │       ├── Models/         مدل‌ها
│   │       ├── Services/       منطق کسب‌وکار
│   │       └── Views/          ویوهای ایزولهٔ ماژول
│   └── Views/              ← لایه‌ها و کامپوننت‌های اشتراکی
├── core/                   ← هستهٔ سبک: Router, Model, View, Auth, Events, …
├── config/                 ← پیکربندی + ماتریس مجوزهای RBAC
├── database/
│   ├── migrations/         ← ۶ مهاجرت SQL (۴۲ جدول با CHECK/REGEXP)
│   └── seeders/            ← دادهٔ نمونهٔ واقع‌گرایانه
├── public/                 ← تنها پوشهٔ عمومی (index.php + assets)
├── storage/                ← لاگ‌ها
├── tests/                  ← PHPUnit (واحد + ویژگی) + اسموک‌تست HTTP
├── docs/                   ← مستندات فارسی
└── bin/faraat              ← کنسول خط فرمان
```

### جریان‌های کسب‌وکار کلیدی (رویدادمحور)

```
ثبت سفارش مشتری (ORD) ──order.placed──→ اعلان به مدیر و مشتری
تأیید مدیر ──order.confirmed──→ ساخت خودکار سفارش تولید (WO)
تخصیص بافنده ──workorder.assigned──→ اعلان پنل بافنده
تحویل بافت ──workorder.delivered──→ ورود به انبار + اعلان بازرسی
تأیید کیفیت ──workorder.qc_passed──→ صدور کدهای اصالت FB + فیش دستمزد PAY
پرداخت فیش ──payment.paid──→ تسویهٔ ماندهٔ بافنده + تکمیل WO
فروش حضوری نمایندگی ──pos.sale──→ فاکتور + رسید RCP + پورسانت COM
```

## 🧪 تست

```bash
php bin/faraat test          # ۱۳۸ تست PHPUnit (واحد + ویژگی) روی faraatbafi_test
bash tests/smoke.sh          # ۷۲ بررسی جریان کامل HTTP روی سرور در حال اجرا
bash tests/crawl.sh          # خزش ۹۹ صفحه با ۶ نقش (شکار خطاهای رندر)
php bin/faraat optimize      # کش مسیرها (production)
php bin/faraat queue:work    # کارگر صف رویدادها
```

> پایگاه دادهٔ تست (`faraatbafi_test`) باید وجود داشته باشد؛ بوت‌استرپ تست خودش آن را می‌سازد و دانه‌گذاری می‌کند.
